no-mintsifra
============

Сайты на сертификатах Минцифры в любом браузере.
Сам сертификат Минцифры не ставится ни в Windows, ни в браузеры.

Как пользоваться
----------------

Дважды щёлкните no-mintsifra.exe. Откроется меню:

  1  Включить обход          один раз, дальше работает сам и после перезагрузки
  2  Выключить и удалить     из системы убирается всё
  3  Проверить               открывает каждый сайт и показывает результат
  4  Обновить список сайтов
  5  Удалить сертификат Минцифры, если он уже стоит в Windows

При включении Windows спросит, доверять ли сертификату
«no-mintsifra local CA». Нажмите «Да». Этот сертификат создаётся
на вашем компьютере и подходит только для доменов из списка.

Если SmartScreen пишет «Windows защитила ваш компьютер», нажмите
«Подробнее», затем «Выполнить в любом случае». Файл не подписан
платным сертификатом разработчика, исходники и сборка открыты:
https://github.com/Nettrove/no-mintsifra
